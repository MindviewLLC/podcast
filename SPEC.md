# Happy Path Programming

This is the website for the Happy Path Programming Podcast by Bruce Eckel & James Ward.

Podcast Description:
> No-frills discussions between Bruce Eckel and James Ward about programming, what it is, and what it should be.

The website has:
- Host list
- Episode list
- Guest list

## Site Structure

### Hosts

Bruce Eckel: https://www.mindviewllc.com/about/
James Ward: https://www.jamesward.com

### Epsides

- Each episode needs a unique URL (for social sharing) like: /episodes/<title>.html
- Episodes are co-derived from
  - YouTube Channel (shorts & videos): https://www.youtube.com/@HappyPathProgramming
  - Spoitfy: https://creators.spotify.com/pod/profile/happypathprogramming/
- Episodes have
  - title
  - description
  - resources
  - links to where to get the podcast (all sources)
  - highlight image
- All episodes should be listed and linkable to their unique pages

### Guest list

- Derived from all past guests (who may have been on multiple episodes)
- Each guest has a unique URL like: /guests/<name>.html
- Name
- BIO
- Episodes

## Updates

This website is regenerated daily and deployed to https://www.happypathprogramming.com

## Architecture

- The website is entirely generated by AI from this file and MUST NOT use build systems.
- Static files in this repo are served directly to the production website - URL paths root are this repo and dir / file names here are exposed directly on the production website.
- You can update @AGENTS.md and @DESIGN.md to make it easier to update the site but don't add scripts or other tools to this repo - it is only for the static assents to be served.
